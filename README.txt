Upload all six app files (index.html, app.js, manifest.webmanifest, sw.js, icon-192.png, icon-512.png) to the root of a GitHub repository. In Settings > Pages choose Deploy from a branch, main, / (root), and Save. Open the published HTTPS URL. Install via browser menu. Visit online once before testing offline. PDF export uses the browser print dialog: select Save as PDF. Backups are unencrypted JSON; keep them private. Storage is per browser and origin. For future updates increment CACHE in sw.js and upload changed files. No external dependencies.
